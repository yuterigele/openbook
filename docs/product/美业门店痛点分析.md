# 美业门店痛点分析

> 面向 1–5 人美发门店的预约与经营痛点。

## 行业现状：3 极分化

### 头部：美团 / 阿里本地生活的“重武器”

- 月活 6 亿+，技术 + 流量 + 地推
- 适合连锁餐饮、SPA、大型医美
- **不适合 1-5 人小门店**（抽佣 15-25%，月单 100 单以下不划算）

### 腰部：美业 SaaS（美约 / 美业帮 / 博卡）

- 4-5 千 / 年，店主学习成本高（“用 SaaS 比雇前台还累”）
- 模板化预约页面、扫码选时间
- **缺点**：顾客需要学新东西（脱离微信），店主功能太多用不上

### 尾部：什么都不用

- 80% 的小门店：**Excel + 微信群 + 老板脑记**
- 痛点最重，付费意愿低（觉得“够用了”）
- **机会**：让“什么都不用”变成“用了反而更省事”

## 8 大真实痛点

### 痛点 1：手工登记 / 记账

```text
症状：忙时漏记、忘发卡、统一活动难落实
成本：每月错 1-2 单 × 客单价 80-300 = 月损失 200-600 元
```

### 痛点 2：顾客爽约

```text
症状：不预付、不绑卡、不算爽约
成本：旺季单店月损失 3-5 个预约 × 80-300 = 240-1500 元
```

### 痛点 3：无实时库存 / 排班

```text
症状：顾客无法在线选空档、换店后丢失历史
成本：顾客“问一下就走”率上升 20-30%
```

### 痛点 4：跨店不互通

```text
症状：预约数据散在 5 个私人微信里
成本：月底对账要 1-2 个晚上
```

### 痛点 5：撞单 / 漏单

```text
症状：2 个顾客都约 Tony 2 点
成本：顾客体验崩，回头客减少
```

### 痛点 6：等候时长无标准

```text
症状：顾客不知道前面还有几位
成本：到店即走的“幽灵顾客”增加
```

### 痛点 7：顾客画像无沉淀

```text
症状：跨员工、跨月无固定消费者档案
成本：营销活动精准度低，复购率差
```

### 痛点 8：违约难管控

```text
症状：缺爽约 / 迟到黑名单
成本：老板难以追踪和管理
```

> 老板一天扮演“客服 + 调度 + 财务”角色，每天 1-2 小时耗在微信上。

## 现有方案为什么没解决

| 方案 | 手工登记 | 顾客爽约 | 撞单 / 漏单 | 违约管理 |
|------|:--------:|:--------:|:-----------:|:--------:|
| 美团 / 阿里 | ✓（系统） | ✓（预付） | ✗ | ✗ |
| 美业 SaaS | ✓ | ✓（绑卡） | ✗ | ✓ |
| Excel + 微信 | ✗ | ✗ | ✗ | ✗ |
